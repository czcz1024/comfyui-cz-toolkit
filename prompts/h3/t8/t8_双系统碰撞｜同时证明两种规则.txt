# 双系统碰撞｜同时证明两种规则
# ID: t8-case-dual-system-convergence-proof-v1
# 来源: T8 非官方案例模板

用途: 先分别建立两个对立系统的独立规则，再让它们一次汇聚形成持久第三状态。
输入格式: 系统A材质/规则 + 系统B材质/规则 + 分别建立 + 一次汇聚碰撞 + 双方共同形成的第三状态
推荐输入: 实验台左侧是会结晶的液态玻璃，右侧是会脉动的磁性沙；分别证明各自规则后，它们只汇聚一次，形成同时透明且持续脉动的悬浮晶格。

必须实现的锚点:
  1. 两个系统先独立成立
  2. 材质或运动规则明确不同
  3. 只发生一次关键汇聚
  4. 第三状态同时保留双方证据
