# 多人攻势接力｜独立入场后同步收束
# ID: t8-case-multi-agent-attack-entry-relay-v1
# 来源: T8 非官方案例模板

用途: 先建立稳定的中央威胁几何与外围团队，再让不同成员以独立入场路线完成各自证明动作；角色职责清楚后才允许路线重叠，最终以同步投入而不是混乱群殴收束。
输入格式: 固定中央挑战 + 至少3个角色/系统 + 各自独立入场路线与职责 + 延迟的高位路线 + 同步收束
推荐输入: 三台原创温室服务机分别从地面、玻璃墙和上方处理同一根结；每条路线先独立证明职责，最后同步拉、稳、冷并完成收纳。

必须实现的锚点:
  1. Establish one spatially persistent challenge field and the full team before any individual entry.
  2. Give the first participant one complete entry path and proof action.
  3. Delay the most displaced entry until earlier roles are readable.
  4. End with synchronized commitment while preserving each participant's route identity.
