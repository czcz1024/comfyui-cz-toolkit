# 双人递进｜共享接触从地面升到空中峰值
# ID: t8-case-shared-contact-height-escalation-v1
# 来源: T8 非官方案例模板

用途: 先建立两个主体的深度差，再让同一次共享接触从低位逐级升高到唯一空中峰值，最后回到地面并停留在可读的关系终态。
输入格式: 两个身份稳定的主体 + 初始距离差 + 低位共同接触 + 至少1次中段升高 + 共享空中峰值 + 落地关系停留
推荐输入: 两台木偶修理机从不同深度靠近，在低位共同托起一枚发光环，经过腰部与头顶两次交接后一起跃到最高点，落回地面并并肩稳住发光环。

必须实现的锚点:
  1. Establish two stable roles and a readable depth or distance gap before contact.
  2. Use one committed approach to create the first low shared contact state.
  3. Reserve one shared airborne or otherwise clearly highest joint event as the apex.
  4. Return both roles to a grounded or baseline plane and hold their post-apex relationship without asserting an unsupported result.

Failure prevention:
- The two roles start tangled together.: Show stable identities and a readable gap before the first shared action.
- The first contact is already maximal.: Begin with one low baseline contact so later states can visibly rise.
- Repeated events stay at one height.: Assign each exchange a higher contact level or larger shared amplitude.
- Several equal aerial peaks compete for attention.: Reserve one unmistakably highest joint event.
- The ending invents a winner or skips the return.: Return both roles to the baseline plane and hold a neutral post-apex relationship.
