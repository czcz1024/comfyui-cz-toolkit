# 分组对话覆盖｜两边接力后全桌合流
# ID: t8-case-subgroup-conversation-recombine-v1
# 来源: T8 非官方案例模板

用途: 先用第一组双人镜头建立共享社交空间，在组内交接可见发言轮次，再切到桌对面的第二组完成独立回应阶段，最后用更宽构图让所有人物和同一桌面锚点合流；来源对白含义未知，只迁移可见轮次与覆盖顺序。
输入格式: 稳定群体空间 + 第一小组可见发言轮次 + 第二小组接力 + 1次非语言动作 + 全体同框收束
推荐输入: 四名原创餐厅工作人员先以两人组建立空间关系，再切到另一两人组完成发言与非语言动作，最后回到四人同框；不规定原片对白含义。

必须实现的锚点:
  1. Establish the first subgroup and shared table anchors before any cross-table cut.
  2. Make speaking-turn ownership visibly readable within the first subgroup without assigning source meaning.
  3. Give the second subgroup one distinct response phase and one listening witness.
  4. Recombine all participants with the same spatial anchors in a held wide view.
