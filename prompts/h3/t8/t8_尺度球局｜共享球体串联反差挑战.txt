# 尺度球局｜共享球体串联反差挑战
# ID: t8-case-scale-mismatch-sports-token-challenge-v1
# 来源: T8 非官方案例模板

用途: 用一个持续可见的球体把尺度反差对手、固定目标和动作阶段串在同一场地：控球建立规则、巨体封锁空间、小体型改变路线、抛物线把挑战推向目标，最后以双方可见反应收束但不臆测得分。
输入格式: 两种明显尺度 + 共享球体或令牌 + 固定目标 + 可见变线 + 单一轨迹 + 不虚构结果的反应终态
推荐输入: 硬币大小的配送机器人控制发光珠，巨型充气守门体封锁桌面通道；机器人变线并把珠子抛向悬空铜环，结尾保持双方和目标同框，不在未确认时宣称成功。

必须实现的锚点:
  1. Establish two clearly different scales, one shared token and one fixed target in the same arena.
  2. Use repeated token control to prove who currently owns the action.
  3. Show one readable token trajectory toward the fixed target.
  4. End on a visible shared reaction state and only claim success if the target result is directly shown.
