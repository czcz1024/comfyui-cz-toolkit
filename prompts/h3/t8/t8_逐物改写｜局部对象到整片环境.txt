# 逐物改写｜局部对象到整片环境
# ID: t8-case-local-object-conversion-to-environment-rewrite-v1
# 来源: T8 非官方案例模板

用途: 保持同一第一视角和真实环境，使用一个持续可见的触发工具依次选中不同尺度对象；每次只改写一个局部对象并保留其位置关系，最后把相同转换规则扩大到整片环境。
输入格式: 连续真实环境 + 可见选择工具 + 至少三次局部对象改写 + 原位空间配准 + 一次整片环境改写
推荐输入: 原创精密洁净室内，戴手套技术员举起小型琥珀检查发射器，对准石墨色阀门，白色墙板、地面网格和传送设备保持真实；光束触及底盘后只有机器人变成分层示意图，轮位、路线和周围机器保持空间配准；光束指向顶棚网格，相同转换边界自上而下扩展，让顶棚、机器和地面成为统一青色洁净室剖面，发射器仍在前景

必须实现的锚点:
  1. Establish one continuous real environment and one visible selection tool.
  2. Align the tool with one object before each local conversion.
  3. Repeat the rule across at least three materially different object scales while keeping geography traceable.
  4. Apply the established rule once to a whole environmental region and hold the boundary.
