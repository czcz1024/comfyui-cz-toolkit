# 动作成字｜方向笔画驱动角色切换与终态标记
# ID: t8-case-direction-stroke-role-switch-v1
# 来源: T8 非官方案例模板

用途: 第一位角色的动作生成强方向笔画，落地后笔画变成构图分隔；第二位角色沿同一图形轴进入并把笔画弯成新几何，最终标记由两次动作共同完成。
输入格式: 第一动作生成方向笔画 + 落地变分隔 + 第二角色沿同轴进入 + 笔画变形 + 无文字终态标记
推荐输入: 蓝色纸艺自动机把炭黑直尺变成构图分隔，琥珀自动机沿同轴进入并把直尺弯成螺旋，两次动作共同形成无文字涡轮标记。

必须实现的锚点:
  1. Bind the first action to one dominant directional stroke.
  2. Use the first landing to change the stroke's composition role.
  3. Let the second action bend or reconfigure the stroke.
  4. Hold one final mark that visibly inherits both actions.
