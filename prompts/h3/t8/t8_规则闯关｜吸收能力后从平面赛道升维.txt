# 规则闯关｜吸收能力后从平面赛道升维
# ID: t8-case-rule-acquisition-dimensional-course-escalation-v1
# 来源: T8 非官方案例模板

用途: 让一个外来主体进入规则清晰的平面路线，先用移动、避障和收集建立关卡语法，再通过一次可见能力获取改变运动方式；临近终点时让同一路线整体升为三维，主体方向、身份和目标连续不断，最终抵达可读终点。
输入格式: 外来主体 + 平面规则路线 + 两种不同基础规则证明 + 一次可见能力触发 + 功能性新运动方式 + 回到可读终段 + 同一路线升维 + 可读终点
推荐输入: 15秒，16:9。琥珀玻璃目录标记进入平面档案索引，先等待扫描条通过，再转动镜面解锁光闸；它只接触一次紫色相位印章，变成半透明并穿过不透明隔板，随后回到同一白色光路。临近终点时索引平面升成立体档案中庭，标记保持方向进入白色归还槽并稳定停留。

必须实现的锚点:
  1. Establish one outsider, one flat rule-bound route and one stable destination direction before any upgrade.
  2. Show the outsider successfully using at least two different base route rules before capability acquisition.
  3. Use the acquired capability to enter a different movement mode while keeping identity and destination continuous.
  4. Return from the upgraded movement to one readable final approach, then extrude the established route near the finish and end at one goal without resetting direction.
