# 日程闭环｜重复锚点串联整日任务
# ID: t8-case-bounded-day-loop-recurring-anchor-v1
# 来源: T8 非官方案例模板

用途: 从一个静止起点出发，用重复人物特征和随身物串联准备、出发、通勤与工作，并在片尾回到与开场相呼应的休息状态；高密度切换仍保持一天的因果顺序。
输入格式: 静止基地与时间提示 + 至少三项准备任务 + 身份/随身物锚点 + 通勤与目的地任务 + 返回基地休息
推荐输入: 原创微缩种子档案馆黎明，一名毛毡管理员躺在叶片吊床旁，黄铜露水钟、三个空种子位和苔藓挎包同框；钟响一次后睁眼；准备完成的管理员离开壁龛，苔藓挎包和一角外露信封持续作为锚点，层层档案架向下滑过；管理员把三封信放回原位，将同一苔藓挎包置于黄铜露水钟下并重新躺进叶片吊床，全部锚点可读

必须实现的锚点:
  1. Open on one inactive base state with a visible time or wake cue.
  2. Build a readable readiness package through at least three distinct preparation duties.
  3. Complete one visible destination duty before beginning the return.
  4. Return the same identity and object anchors to the original base and settle into a resting state.
