# 光学搜索｜远景线索递进到细节确认
# ID: t8-case-optical-search-evidence-contraction-v1
# 来源: T8 非官方案例模板

用途: 让同一受限光学视野承担完整搜索：先锁定远处地点，再沿一个可见异常逐级收紧到结构、主体和局部细节；每次靠近都回答一个更具体的问题，最后用极近特征完成确认而不是再切到全知镜头。
输入格式: 受限光学观察界面 + 远景地点线索 + 中景主体定位 + 近景身份细节 + 极近景反射或局部证据确认
推荐输入: 原创轨道温室环位于黑色太空中，下方支杆、三段浅色外壳和青色状态灯建立地点锚点；一台黄铜维护自动机沿环轨移动并用单根探针测试冻结接头，圆形检查镜始终存在；自动机举起一枚弧形玻璃密封圈，反射中清楚出现开场温室环、下方支杆和仍脉动的霜缝

必须实现的锚点:
  1. Establish one persistent constrained optical interface and a distant geographic anchor.
  2. Identify one unusual structural cue inside the same observed geography.
  3. Stabilize one closer identity or function proof before the terminal detail.
  4. End on one micro-detail that visibly echoes or verifies the opening geographic anchor.
