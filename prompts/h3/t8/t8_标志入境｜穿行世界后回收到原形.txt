# 标志入境｜穿行世界后回收到原形
# ID: t8-case-emblem-world-return-loop-v1
# 来源: T8 非官方案例模板

用途: 先把一个简洁标志当作入口和几何规则，进入由其形状、色彩与方向构成的三维世界；经过环境、角色与一次尺度跃迁后，所有结构必须可追溯地重新折回同一个标志。
输入格式: 稳定标志 + 三维世界展开 + 中心角色动作 + 一次尺度跃迁 + 同一标志精确回收
推荐输入: 一枚原创铜质罗盘玫瑰只旋转一次并锁定，四片叶瓣展开成实体水道，镜头穿入奶油色玻璃温室；种子保管自动机转动一次阀门，水脉同时传到四条通道，地面仍能读出罗盘结构；已建立的塔叶、骨架、阀块和水道依次向内折叠，精确重建开场同一铜质罗盘玫瑰，不出现新文案

必须实现的锚点:
  1. Begin with one compact emblem that clearly defines geometry, palette and direction.
  2. Expand the emblem into a navigable environment using repeated versions of its own components.
  3. Use one major scale change to gather the environment into a simplified global form.
  4. End by rebuilding and holding the same opening emblem from visible world components.
