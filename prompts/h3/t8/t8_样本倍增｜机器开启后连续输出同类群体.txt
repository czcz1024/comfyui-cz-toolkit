# 样本倍增｜机器开启后连续输出同类群体
# ID: t8-case-exemplar-triggered-output-multiplication-v1
# 来源: T8 非官方案例模板

用途: 先让一个可辨样本与封闭机器同框，经过一次外部触发后打开独立输出阈值；同类实例从阈值连续出现并在机器周围累积，而原样本始终留在顶部作为身份对照，最终同框证明倍增结果。
输入格式: 样本与封闭机器同框 + 一次外部触发 + 独立输出阈值打开 + 同类实例连续输出累积 + 原样本保留为身份对照
推荐输入: 原创纸艺天文工坊内，一台黑黄铜立式折叠织机保持关闭，一枚清晰黄铜折纸星放在顶部对照托架，奶油色脚踏板同时可见；第一枚匹配的黄铜折纸星从侧槽折出并挂到一根空线，顶部原样本仍留在独立托架；顶部原样本、中央织机、仍开启的侧槽和四枚不同深度的匹配星同时可见，形成完整小型星座

必须实现的锚点:
  1. Establish one identity exemplar and one closed production device in the same readable frame.
  2. Use one visible trigger and show a distinct output threshold opening before the first result.
  3. Repeat one-at-a-time outputs through the same threshold and accumulate them in visible space.
  4. Hold exemplar, device, open threshold and accumulated outputs together.
