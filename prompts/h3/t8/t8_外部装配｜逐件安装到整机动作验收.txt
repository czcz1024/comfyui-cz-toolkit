# 外部装配｜逐件安装到整机动作验收
# ID: t8-case-external-assembly-integrated-audition-v1
# 来源: T8 非官方案例模板

用途: 让大尺度外部操作手逐件改变一个稳定主体，每次安装都先用近景证明接合，再回到全身状态确认累积结果；完成细节校准后，必须用一段完整动作测试证明所有部件能共同工作。
输入格式: 稳定基础主体 + 分阶段外部装配 + 接合近景与全身复核 + 细节校准 + 整机动作验收
推荐输入: 原创轨道仪器工坊内，一具掌心大小的铜质躯干立在空白校准标记上，两只大型象牙色维修手套安装双腿行走底座；主轮廓完成后，手套安装一支压力探针，并让面罩对齐三条刻度，不新增大型结构；自动机走三步、只展开一次双翼并用探针测量一条可见气流带，所有部件保持连接，最后完整定格

必须实现的锚点:
  1. Establish one stable subject, assembly station and unmodified baseline.
  2. Install major components one at a time and return to a whole-subject check after each stage.
  3. Complete all small functional or decorative components before testing motion.
  4. End with one integrated movement audition and a held complete state.
