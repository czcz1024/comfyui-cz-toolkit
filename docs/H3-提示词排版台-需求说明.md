# H3 提示词排版台 — 完整需求说明

> 产品节点：`CzH3PromptFormatter`（显示名：**H3 提示词排版台**）  
> 分类：`CZ/H3`  
> 仓库：`ComfyUI-CZ-Toolkit`  
> 文档版本：与当前实现同步（2026-08）  
> 定位：**排版 / 结构化拼装**，不接 LLM；对齐 MiniMax Hailuo H3 / 官方提示词结构。  
> 修改记录 / 踩坑：`docs/H3-提示词排版台-修改记录.md`

---

## 1. 目标与非目标

### 1.1 目标

1. 在 ComfyUI 内提供可视化表单，覆盖五种生成模式的 H3 英文提示词拼装。
2. 用户主要填「故事、引用用途、分镜正文、声音」；输出官方字段结构的完整 `prompt`。
3. 同时输出结构化包 `H3_PROMPT_PACK`，供下游节点按字段消费（不必再解析全文）。
4. 可接 `H3_MEDIA_BUNDLE`（H3 参考素材），按接线自动判模式、增量同步引用卡。
5. 表单状态可保存 / 加载 JSON；工作流内由隐藏 widget 持久化。

### 1.2 非目标

- 不调用大模型写提示词（旧「H3 提示词向导（表单）」已删除，本节点取代其产品位）。
- 不在节点内跑图 / 调 Hailuo API（只产出文本与结构包）。
- 不替代官方写作指南；拼装规则应对齐官方 base / ref 指南。

## 2. 五种模式

| 模式 ID | 标签 | 格式 | 含义 |
|---------|------|------|------|
| `t2va` | T2VA | base 三字段 | 纯文生视频 |
| `i2va` | I2VA | base 三字段 | 首帧图驱动 |
| `fl2va` | FL2VA | base 三字段 | 首尾帧驱动 |
| `l2va` | L2VA | base 三字段 | 尾帧驱动 |
| `ref2va` | Ref2VA | ref 六字段 | 多图 / 视频 / 音频参考 |

### 2.1 模式自动判定（素材包识别时）

1. 只要接了 **`ref_image_*` / `ref_video_*` / `ref_video_audio_*` / `ref_audio_*`** 中任一 → **强制 Ref2VA**。
2. 否则仅看首尾帧：
   - 首 + 尾 → FL2VA  
   - 仅首 → I2VA  
   - 仅尾 → L2VA  
   - 都无 → T2VA  

> 约定：除「首帧图 / 尾帧图」外只要有其它素材口接线，就一定是 Ref。

### 2.2 字段结构（拼装结果）

**Base（T2VA / I2VA / FL2VA / L2VA）**

- （可选）首行对齐句 `referenceHeader`（I2VA / FL2VA / L2VA）
- `integrated_multimodal_description`：分镜时间线正文
- `overall_soundscape`
- `non_diegetic_music`

**Ref（Ref2VA）**

- `subject_definitions`
- `summary`（可带任务类型方括号前缀）
- `retention_analysis`
- `detailed_description`（开场风格 + 分镜）
- `overall_soundscape`
- `non_diegetic_music`

## 3. Comfy 节点接口

### 3.1 输入

| 名称 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `media_bundle` | `H3_MEDIA_BUNDLE` | 否 | 接「H3 参考素材」或经提示词框等透传；**execute 不消费**，仅供前端认线 / 识别引用 |
| `form_state` | STRING（隐藏） | 是 | 界面维护的完整表单 JSON |
| `prompt` | STRING（隐藏） | 是 | 界面拼装的完整提示词 |
| `prompt_pack_json` | STRING（隐藏） | 是 | `H3_PROMPT_PACK` 的 JSON 序列化 |

> 时长**不**再作为节点 FLOAT 控件展示（避免挡住 DOM 面板）；时长在界面「总时长(s)」编辑，execute 时从 `form_state.duration` 读取。

### 3.2 输出

| 名称 | 类型 | 说明 |
|------|------|------|
| `duration` | FLOAT | 目标时长（秒，两位小数） |
| `prompt` | STRING | 完整 H3 英文提示词（可直接下游使用） |
| `prompt_pack` | `H3_PROMPT_PACK` | 结构化包（见下节） |

### 3.3 Python 行为

- 拼装逻辑在前端完成；Python `emit()` **直通** `prompt` + 解析后的 `prompt_pack`，`duration` 从 `form_state` 取。
- 隐藏 widget 由前端 `postMessage` 同步，保证 Queue 时值已写入。

## 4. `H3_PROMPT_PACK` 结构

```text
packVersion: number          # 当前为 1
mode: string                 # "T2VA" | "I2VA" | "FL2VA" | "L2VA" | "Ref2VA"
structured:
  referenceHeader: string | null     # base 对齐句；Ref 为 null
  globalStyle: string | null         # Ref 开场风格；base 为 null
  summary: string | null             # 仅 Ref
  subjectDefinitions: string | null  # 仅 Ref
  retentionAnalysis: string | null   # 仅 Ref
  shots: ShotItem[]
  overallSoundscape: string | null
  nonDiegeticMusic: string | null
```

**ShotItem**

| 字段 | 说明 |
|------|------|
| `index` | 0-based |
| `cutTime` | 第 0 镜为 `null`；其后为切点时刻字符串（如 `00:02.000`） |
| `body` | 镜内正文（可含说话人 Sx 规范化） |
| `raw` | 该镜完整输出行（含 `[Shot N]` / 时间戳等） |

缺省字段一律用 `null`，不用空字符串冒充「有内容」。

## 6. 引用定义（Ref2VA）

### 6.1 类型与编号

- 三种：`picture` / `video` / `audio`  
- **按类型分别编号**：`<Picture 1>`…、`<Video 1>`…、`<Audio 1>`…  
- 与素材包槽位约定对应：  
  - `<Picture N>` ↔ `ref_image_{N-1}`  
  - `<Video N>` ↔ `ref_video_{N-1}`  
  - `<Audio N>` ↔ `ref_audio_{N-1}`  

### 6.2 卡片 UI 要求

- 显示 **`#N` + `<Picture N>`（或 Video/Audio）**  
- 显示槽位提示（已接线则显示 `source_input`；否则「应对接 ref_image_N」）  
- **类型在添加时锁定**（手加选 Picture/Video/Audio，或识别自素材包）；创建后不可改；换类型需删卡重加  
- **上移 / 下移**：仅在**同类型**内交换顺序，从而交换编号  
- 可删除；手加与包识别来的卡均可  

### 6.3 用途（role）— 按类型分套

- **Picture**：仅供 Subject / 关键帧 / 分镜参考等  
- **Video**：仅供 Subject / 源视频改片续拍 / 结构参考等  
- **Audio**：音色参考 / 拷贝音轨 / 环境音效 / 配乐参考等  

「仅供 Subject」时：本卡不单独出 retention 行；保真度写在 Subject 卡上。

### 6.4 主体（Subject）与关联性

- Subject **彼此不在定义表里互绑**；各自绑定到 Picture/Video/Audio。  
- Subject 之间的剧情关系（如「女人开车」）写在 **summary / 分镜正文**，用 `<Subject 1>`、`<Subject 2>` 同句出现表达。  
- 绑定（binds）：外观 / 动作等 **aspect ← 某引用标签**。

## 7. 素材包自动识别 / 同步

### 7.1 入口

- 接线变化：只更新「已连接 · 模式提示 · 数量」状态条，**不**自动改引用卡 / 模式  
- 按钮「识别」：向父页拉取最新接线，再增量同步引用卡与模式（唯一改卡入口）  

### 7.2 增量合并规则（关键）

| 情况 | 行为 |
|------|------|
| 新槽位 | 新增引用卡，填默认用途 / 说明种子 |
| 已有同 `source_input` | **只更新** kind / token / label 等包侧元数据；**保留**用户已填 note / role / retain / retainNote |
| 包内曾识别、现已断开 | **删除**该卡 |
| 无 `sourceInput` 的手加卡 | **一律保留** |
| 删除包内卡后 | 清理 Subject.binds 中指向已删 ref 的项 |

### 7.3 认线规则（防误判）

- 一条连线只归属「真正挂着该 link id」的输入口。  
- **禁止**空的 `first_frame` 按下标抢走尾帧 / ref 的线。  
- 只接尾帧 → L2VA · 图1（尾帧），不得变成首帧 / FL2VA。  
- 只接 `ref_*` → Ref2VA + 参考图/视频/音频卡，不得误判为首帧。

## 8. 分镜与工具

### 8.1 时间线

- 第 1 镜无切点时间戳；后续镜递增切点。  
- 总时长与末镜 end 联动；支持时间轴拖拽调整。  
- 常用范围约 4～15s（校验提示，不强制锁死）。  

### 8.2 镜内工具（写入正文，不另开 Shot）

- 运镜（类型 + 幅度 + 速度）  
- 镜内时间（「For the first two seconds…」类散文，**不**新开 Shot 时间戳）  
- 对白 / 合唱 / 演唱（含画外、scenetrans、cutoff 等能力）  
- 画内声效  
- AU 表情选择器（强度 0–5）  
- `@` 插入引用 / Subject 标签（仅 Ref）  

### 8.3 说话人

- 从正文收集说话人，编 `(S1)(S2)…`  
- 组对白 / together 等句式规范化

## 9. 校验

- **error**：必须处理（如无效时长、无 Shot 等）  
- **warn**：建议处理  
- 不自动改稿，只报告  
- 点「校验」后展开校验区；编辑时若已校验过则静默刷新摘要

## 10. 持久化

| 方式 | 说明 |
|------|------|
| Comfy 工作流 | `form_state` / `prompt` / `prompt_pack_json` 隐藏 widget |
| 导出 JSON | `format: h3-prompt-formatter-lab`，含 `state` + `output` 快照 |
| 导入 JSON | 兼容 `{ format, state }` 或裸 state；折叠状态一并恢复 |

**不要**用 `form_state` 作为连线输入类型；持久化只走节点内部 JSON。

## 12. 下游约定（建议）

- 独立使用：下游用自己的模式 / 时长 / 提示词控件。  
- 接入本节点：`duration` / `prompt` 直连；需要拆字段时读 `prompt_pack.structured.*`，分镜用 `shots[i]`。  
- 若将来做「pack 覆盖下游下拉」：仅在 `prompt_pack` 已连接时覆盖；未连接时保持下游本地选择（产品备忘，未强制实现）。

## 13. H3 写作备忘（产品内共识）

1. **同一连续人脸 / 同一镜**：优先一个 `[Shot N]`；镜内变化用散文时间，不要滥加切点。  
2. **画外 / scenetrans / cutoff**：按官方句式写在对白或正文。  
3. **音频**：可音色参考（不必字字对齐）；拷贝轨需匹配 `<d>` 等拷贝约定。  
4. **续拍**：上一段成片作 `<Video>` + continuation 类任务/说明。  
5. **Subject 关系**：定义分开，关系写在叙事句里。
