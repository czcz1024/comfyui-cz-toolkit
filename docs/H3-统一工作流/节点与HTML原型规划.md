# H3 统一工作流 — 节点与 HTML 原型规划

> 配套：`开发说明.md`（需求总纲）  
> 开发策略：**先 HTML 模拟操作与数据契约 → 你试用确认 → 再落成真正 ComfyUI 节点**  
> 状态：规划中 / 未实现  
> 日期：2026-09

---

## 1. 为什么先做 HTML

| 原因 | 说明 |
|------|------|
| 交互重 | 多段切点、每段素材/文案、镜间续或新，适合先在浏览器里把「好不好用」试清楚 |
| 契约先稳 | HTML 与日后节点共用同一套 **Plan JSON / Prompt Pack**，避免节点写完再推翻 UI |
| 风险低 | 不先绑 Comfy 执行图、不先碰采样循环；确认后再嵌进节点 DOM 或侧栏 |
| 有先例 | 本仓库已有 `h3-prompt-formatter-lab` + 排版台嵌入路径，可复用这套「Lab → 节点」节奏 |

### 1.1 推荐目录（实现时）

```text
ComfyUI-CZ-Toolkit/
  docs/H3-统一工作流/          ← 需求与本规划
  h3-unified-lab/              ← 新建：纯静态/本地 HTML 原型（模拟操作）
    index.html                 ← 入口：单段 / 多段导演台切换
    …                          ← 与日后 web/ 共用的 schema、样式可再抽
```

Lab **不调用**真实 H3 采样；可用假数据、本地 JSON 导入导出、可选接已有 LLM HTTP（若你已有）——第一版甚至可全 mock。

### 1.2 Lab 分屏（建议你先试用的页面）

| 页 | 对应日后能力 | 试用要确认什么 |
|----|--------------|----------------|
| **A. 单段控制台** | 生成模式下拉、LLM 开/关、二采开/关、想法→prompt、素材槽位列表（模拟 Load 结果） | 单段心智是否够用 |
| **B. 多段导演台** | 波形/切点、段列表、每段素材引用、文案、镜间关系、选段 | 人机共驾是否顺手 |
| **C. 计划 JSON 预览** | 导出/导入 `H3_SEGMENT_PLAN` | 字段是否够、改起来是否直观 |

确认顺序建议：**先 A → 再 B → 契约锁定后再写节点**。

## 2. 节点总览：复用 vs 新建

原则：**能复用的不新建；新建的尽量薄；重 UI 集中在一个「导演台」节点。**

### 2.1 已有（保留 / 轻改，不算「新开产品」）

| 显示名 | 类 / 现状 | 统一工作流中角色 |
|--------|-----------|------------------|
| Load Image / Video / Audio | 官方 | 唯一素材入口 |
| H3 参考素材 / 素材解包 | 已有 | 打包 / 解包 |
| H3 参数包装 | → 收束为 Brief | 可选 LLM 的上游 |
| LLM 加载器 / 生成 | 已有 | 可选写 prompt |
| H3 提示词框 / 排版台 / 接收并编辑 | 已有 | 手写与手改 |
| 官方 MiniMaxH3* + 采样 | 官方 | 真正出片 |

### 2.2 建议新建节点（目标态，试用确认后再做）

| 代号 | 建议显示名 | 是否新开发 | 自定义编辑器 | 优先级 |
|------|------------|------------|--------------|--------|
| **N1** | H3 提示词归一 | 新建（或排版台抽逻辑） | 否（或轻量校验面板） | P2 |
| **N2** | H3 模式路由 | 新建（也可先用工作流 Switch 代替） | 否 | P3，可延后 |
| **N3** | **H3 多段计划台（导演台）** | **新建** | **是（核心）** | P5；**HTML Lab 先做** |
| **N4** | H3 计划草案 | 新建（可并入 N3 的「生成草案」按钮） | 否 | 与 N3 同批；可先做在 Lab |
| **N5** | H3 当前段取出 | 新建 | 否 | P5 |
| **N6** | H3 段结果登记 / 选片合并 | 新建（可拆两个） | 选片需轻量 UI | P6 |

**结论（数量）：**

- **必做新节点**：约 **3～4 个**（N1 + N3 + N5，N4 可并进 N3）。  
- **可选薄节点**：N2、N6。  
- **不新建、靠开关/接线**：LLM 用不用、二采开不开（工作流旁路或 N3/全局布尔即可）。  
- **重型自定义编辑器**：**主要就 N3 导演台一处**（单段 Lab 可并进同一 HTML，落节点时单段仍可用普通控件 + 已有排版台）。

## 3. 各节点说明书（目标接口）

以下类型名以规划为准；落地时可映射为 `H3_SEGMENT_PLAN`、`H3_PROMPT_PACK` 等字符串/自定义类型。

---

### N1 — H3 提示词归一（`H3PromptNormalize`）

**干什么：** 把 LLM 草稿或手写英文收成可喂官方的最终 `prompt`（+ 可选 pack）；不跑模型、不采样。

| | |
|--|--|
| **输入** | `prompt_raw`（STRING）；可选 `mode`；可选 `prompt_pack` / `media_bundle`（校验引用） |
| **输出** | `prompt`（STRING）；`prompt_pack`（`H3_PROMPT_PACK`）；可选 `ok` / `warnings`（STRING） |
| **参数** | `strict`（布尔：不合规是报错还是仅警告）；`mode` 下拉（可与输入二选一） |
| **编辑器** | 否；警告可打在节点文本上 |
| **HTML Lab** | 单段页里「归一预览」按钮即可模拟 |

---

### N2 — H3 模式路由（`H3ModeRouter`）（可选）

**干什么：** 按生成模式把「同一套 prompt + 解包媒体」接到对应官方条件路径的语义整理；或输出 `mode_resolved` 供下游 Switch。

| | |
|--|--|
| **输入** | `mode`（自动/T2VA/…）；`media_bundle` 或解包后各 IMAGE；`prompt` |
| **输出** | `mode_resolved`；透传 `prompt`；可选「缺失素材」错误 |
| **参数** | `mode`；`on_mismatch`：报错 / 禁止静默降级 |
| **编辑器** | 否 |
| **说明** | 第一期可用 **示例工作流 + Switch** 代替本节点；Lab 用下拉模拟即可 |

---

### N3 — H3 多段计划台 / 导演台（`H3SegmentDirector`）★ 核心

**干什么：** 人机共驾的中枢。持有并编辑整份 **多段计划**；支持自动草案载入后人工改切点、每段素材引用、文案、镜间关系；**不负责**真正采样（采样在官方节点 / 外层循环）。

| | |
|--|--|
| **输入** | 可选 `audio`（AUDIO，用于波形与按时长切段）；可选 `draft_plan`（STRING/PLAN，来自 N4）；可选全局 `media_bundle`（素材库清单，供每段引用 id）；可选 `llm_prompt` 批量结果 |
| **输出** | `plan`（`H3_SEGMENT_PLAN`）；`boundaries_json`（切点秒数，便于对接 T8 类工具）；`active_segment_index`（INT）；当前段摘要字段（可选拆出） |
| **参数（节点级）** | `project_name`；`enable_refine_default`（二采默认，可被每段覆盖）；隐藏 widget：`plan_json`（持久化，与排版台同类） |
| **编辑器** | **是 — 导演台级自定义 UI**（见 §5） |
| **HTML Lab** | **主原型页面**；先在此定交互，再嵌 Comfy |

**计划内每段建议字段（编辑器编辑的对象）：**

```text
segment_id, start_s, end_s,
mode,                    # 生成模式，可继承全局；决定 LLM 用哪份内置 system
continuity,              # continue | new   （接上镜 | 全新镜头）
refine,                  # bool 可选二采
media_refs[],            # 引用素材库 slot / token，非上传文件
prompt_zh,               # 用户中文意图（主写作区）
prompt_draft,            # 自动/规则草稿（可中文或占位）
prompt_final,            # 英文定稿（手写或 LLM 写回；生成前应可用）
notes, seed, …
```

**提示词归属：** 每段中文/英文都在导演台写；台上可点「本段转英文 / 全部未定稿段转换」（内部按段多次调本地 LLM）。输出仍是 **plan**，不是视频。

**本地 LLM（导演台）：** 台内 HTTP → 本机 `llama-server` OpenAI 兼容口（Qwen GGUF 等）；按段 `mode` 切换内置 system（与 `prompts/h3/official/` 共用）。不接云 API。详情见 `开发说明.md` §6.5～§6.7。

**不做：** 节点内上传图；一键无人值守跑完全片；一次 LLM 请求塞全片所有段当主路径。

---

### N4 — H3 计划草案（`H3PlanDraft`）（可并入 N3）

**干什么：** 从音频（及可选全局说明）生成**可编辑草案**：切点列表 + 每段 draft 文案 + 默认 `continuity`。类 T8 Planner，但输出进 N3，不直接开跑。

| | |
|--|--|
| **输入** | `audio`；可选 `full_track_audio`；可选 `brief`（STRING 全局中文/英文说明）；可选 `reference_hints` |
| **输出** | `draft_plan`（同 PLAN 结构，标记 `status=draft`） |
| **参数** | `target_seg_seconds`；`method`（energy / manual_only…）；`default_continuity`（continue/new） |
| **编辑器** | 否（结果进 N3 改） |
| **合并策略** | 若嫌节点多：N3 内「生成草案」按钮 + 后端同一函数，**不单独注册节点** |

---

### N5 — H3 当前段取出（`H3PlanSegmentPeek`）

**干什么：** 从 `plan` + `segment_index` 取出**这一段**喂给下游：时间窗、prompt、continuity、refine 开关、该段 media 引用列表（再接到 Unpack / 官方节点）。人机共驾的「选段执行」靠它。

| | |
|--|--|
| **输入** | `plan`；`segment_index`（INT，可来自 N3 的 active） |
| **输出** | `prompt`；`duration`；`continuity`；`refine`（BOOLEAN）；`start_s`/`end_s`；`media_ref_list` 或直接可选 IMAGE 口（若图已在图内用 Switch 接好则只出引用 id） |
| **参数** | 无或仅 `pad_seconds` |
| **编辑器** | 否 |
| **说明** | 真正「按引用取到 IMAGE」仍靠：图上多个 Load → 素材包 → 按 id 选择；N5 尽量出 **id/token**，避免在节点里藏图 |

---

### N6 — 段结果登记 / 选片合并（后期）

**干什么：** 记录每段多版本路径、选中版本、拼接。对标 Easy Combine 的「选片」产品点，自建简单目录即可。

| | |
|--|--|
| **输入** | `plan`；`segment_index`；`video`/`frames`；`version_label` |
| **输出** | `project_manifest`；最终 `VIDEO`（合并节点可另拆） |
| **编辑器** | **轻量**：版本缩略图对比即可，不必上满编 NLE |
| **优先级** | P6；Lab 可用「假版本列表」模拟 |

---

### 不单独建节点的能力

| 能力 | 做法 |
|------|------|
| **LLM 用/不用** | 导演台按钮有无 / 图上是否接生成节点；Lab 用开关或 mock HTTP |
| **二采用/不用** | 工作流旁路，或 plan/段上 `refine` 布尔 + 下游 If；Lab 用开关 |
| **单段五模式** | 已有素材包 + Brief/排版台 + 官方；Lab 单段页；不一定新节点 |
| **llama-server** | 不做成「生视频节点」；台内/可选路由调本机 chat；与 N3 配套文档或小工具拉起 |

## 4. 推荐接线关系（目标态示意）

```text
[Load*] → 参考素材 → 素材库 bundle ──┐
AUDIO ──→ (N4 草案) ──→ ★ N3 导演台 ←─┘
                         │ 台内可选：按段 HTTP → llama-server → 写回 prompt_final
                         │ plan（多段规则，不是成片）
                         ▼
                    N5 当前段取出 → prompt_en / continuity / refine / refs
                         │
         ┌───────────────┼───────────────┐
         ▼               ▼               ▼
   （可选）N1 归一   官方条件+采样   （可选）二采旁路
         │               │
         └──────→ N6 登记 / 视频拼接
```

单段简化：不经 N3/N5，直接 Brief→(LLM)→N1→官方；（可选）二采。

## 5. 自定义编辑器需求（哪些要「像导演台」）

| 节点 | 是否需要 | 规格 |
|------|----------|------|
| N3 多段计划台 | **必须** | 见下「导演台 UI」 |
| N6 选片 | 建议有 | 缩略图 + 选中版本，远小于 N3 |
| N1 / N2 / N4 / N5 | **不需要** | 标准 Comfy 控件即可 |
| 已有排版台 | 已有自定义 DOM | 继续服务单段结构编辑；多段正文可「打开某段用排版台」或导演台内嵌简表单 |

### 5.1 导演台 UI（N3 / HTML Lab B 页）建议模块

1. **时间轴 / 波形区**：显示音频；切点可拖、可增删；显示各段色块。  
2. **段列表**：序号、起止时间、continuity（接上镜/新镜头）、refine 勾选、模式。  
3. **段详情**：  
   - 素材：从「已接入素材库」勾选/排序（**不是上传**）；显示 `<Picture N>` 预览名。  
   - **中文主写作区** + 英文定稿区（或 draft/final）；「本段 LLM 转换」「全部未定稿转换」（Lab 可 mock HTTP）。  
   - 路线 mode 下拉（决定 system）；continuity；refine。  
4. **工具条**：生成草案、导入/导出 JSON、设当前段、（标注）仅重跑当前段；可选填写 `llama-server` base URL。  
5. **全局**：项目名、默认二采、默认 continuity。

**明确不做进导演台：** 文件上传控件；内嵌完整剪辑时间线轨道（多轨 NLE）；自动开跑全曲无确认；云端提示词 API 作为默认依赖。

---

## 5.2 补充：LLM 与组合（与开发说明对齐）

- 导演台出 **plan**；LLM **按段多次**调用；结果写回各段 `prompt_final`（文案组合）。  
- H3 **按段多次**采样后再拼接（视频组合）。  
- 后端：**本机 llama-server**（推荐）≠ Easy 云 API；进程内 `LLMGenerator` 留给单段图。

## 6. HTML Lab → 节点 的落地顺序

| 步 | 做什么 | 产出 | 你的动作 |
|----|--------|------|----------|
| **L0** | 定 `H3_SEGMENT_PLAN` JSON schema（可写进本目录 `schema-plan.md`） | 契约草稿 | 看字段是否缺 |
| **L1** | HTML **单段控制台**（模式 / LLM / 二采 / 假素材槽 / 假归一） | `h3-unified-lab` | 试用手感 |
| **L2** | HTML **多段导演台**（波形可用假波形或 Web Audio 解码本地文件） | 同目录 | **重点试用** |
| **L3** | Lab 导入导出 plan，与文档验收清单对齐 | 稳定 JSON | 确认「可以做节点了」 |
| **C1** | 将导演台嵌成 N3；plan 进隐藏 widget | 真节点 | 接线试 |
| **C2** | N5 +（可选）N4 合并策略；示例工作流 | 可选手动逐段跑 | — |
| **C3** | N1；二采旁路示例；再 P6 选片 | — | — |

在你确认 L2/L3 之前，**不实现** Comfy 侧 N3/N5 正式节点（避免返工）。
