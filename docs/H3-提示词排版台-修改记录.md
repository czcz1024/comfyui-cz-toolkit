## 2. Bug 与修复记录

### B01 — 节点上的 `duration` 控件挡住排版台顶栏

- **现象**：DOM 面板上方露出半截 `duration` 标签，叠在「排版台」上。  
- **原因**：`duration` 作为 FLOAT widget 仍被 LiteGraph 绘制；简单 `computeSize→[0,-4]` 藏不干净。  
- **修复**：从 `INPUT_TYPES` **去掉 duration 控件**；界面内「总时长」编辑；execute 从 `form_state.duration` 读取。  
- **防再发**：不要再给本节点加会画在 DOM 面板上方的可见 FLOAT/控件；隐藏要用 `converted-widget` + 不画，或根本不要注册该 widget。

### B02 — 校验结果只看见半行字

- **现象**：「校验通过（有建议）」被裁成半截。  
- **原因**：右侧 flex 里 `validate-panel` 默认可被挤扁（`flex-shrink`），`overflow` 后只露出一行中间。  
- **修复**：校验区 `flex: 0 0 auto`；预览区让高；embed 取消死卡 `max-height: 620`；校验/最终提示词改为可折叠区块。  
- **防再发**：右侧栏新增条带时默认 `flex-shrink: 0`；可滚动区才 `flex:1; min-height:0`。

### B03 — 只接尾帧，识别成首帧 / FL2VA·图2

- **现象**：只连「尾帧图」，状态却像首帧或 FL2VA、图2。  
- **原因**：认线「仅按下标兜底」：空的 `first_frame`（下标 0）在槽位压缩后，把真正接到尾帧/ref 的线 **偷走**。  
- **修复**：一条线只归「挂着该 link id」的口；禁止空口按下标抢线；packManifest 按 `collectPackWires` 归属。  
- **防再发**：**永远不要**对 `first_frame`/`last_frame`/`ref_*` 做「未接线口 + 纯下标」认线。改认线先写单测/手测矩阵（见 §3）。

### B04 — 接 ref，也被识别成首帧

- **现象**：连 `ref_image_*` 等，模式/卡片仍像首帧。  
- **原因**：同 B03；`hasRef` 路径没走到或线被算到 first_frame。  
- **修复**：同 B03；有任一 `ref_*` → 强制 Ref2VA + 参考卡。  
- **防再发**：验收「只接 ref_image_0 → Ref2VA · 参考图1」。

### B05 — 再次识别会冲掉已填说明

- **需求**：改接线后同步，不能整表删建。  
- **规则（已实现）**：按 `source_input` 增量合并——保留 note/role/retain；新槽追加；断开的包内卡删除；无 `sourceInput` 的手加卡保留。  
- **防再发**：禁止 `state.refs = []` 再全量重建（除非用户点「重置」）。

### B06 — 断开 audio 后再识别，卡还在

- **现象**：第一次识别出 audio 卡，拔掉线再识别，卡不消失。  
- **原因**：  
  1. `setBundle(null)` 时没跑清理；  
  2. 「识别」按钮用了过期的 `linkedBundle`，没向父页拉最新接线。  
- **修复**：空包 / null → `clearBundleLinkedRefs()`；按钮发 `h3-formatter-request-import` 强制按当前图同步；删除卡时清 Subject.binds。  
- **防再发**：任何「同步引用」必须以 **当下 graph 接线** 为准，不能只信内存里的旧 manifest。

### B07 — 引用类型下拉可乱改，和 ref0/ref1 对不上

- **现象**：两张 Picture 看不出编号，且可改成 Video，打乱与 `ref_image_N` 的对应。  
- **修复**：显示 `#N` + `<Picture N>` + 槽位提示；同类型上移/下移；**类型创建后锁定**（只读），换类型只能删了重加。  
- **防再发**：不要恢复 `data-ref-kind` 下拉；编号算法保持「按类型分别计数」。

### B08 — 「@ 引用」按钮点了没反应

- **现象**：分镜工具栏 @ 无菜单。  
- **原因**：  
  1. 打开菜单的同一次 `click` 冒泡到 `document`，立刻 `hideMention()`；  
  2. 找不到 textarea 时 `return` 无提示；  
  3. 菜单可能被 overflow 裁切 / 定位到屏外。  
- **修复**：打开时 `stopPropagation`；用 `pointerdown`（capture）关菜单并排除 @ 按钮；失败有 status；菜单挂 `body` + 向上翻定位；summary 侧加 @。  
- **防再发**：浮层「打开」与「点外面关闭」不能绑在同一次 bubble click 上；iframe 内浮层优先 `position:fixed` + 挂 body。

### B09 — Lab「输出预览 / 底栏说明」无用且占地方

- **现象**：右侧「输出预览（三个连线口）」+ 底栏「输出：duration+prompt…」。  
- **修复**：整段 UI 删除；真输出仍是 Comfy 口。  
- **防再发**：不要再做「模拟连线口」预览区（易与真节点口混淆）。

## 3. 认线手测矩阵（改认线必跑）

| 接线 | 期望模式 | 期望卡 |
|------|----------|--------|
| 仅首帧 | I2VA | 首帧 / Picture1 |

| 首+尾 | FL2VA | 首+尾 |

| 仅 audio 再断开 | 同步后 | audio 卡删除 |

### B10 — 曾误做成「接线即自动识别」

- **现象/反馈**：用户不希望改素材包接线就自动变引用卡与模式。  
- **修复**：`autoImport` 仅在按钮 `h3-formatter-request-import` 时为 true；接线/就绪只 `setBundle` 刷新状态。  
- **防再发**：不要把 `refreshFormatterNodes` / `onConnectionsChange` 再改回 `autoImport: true`。
